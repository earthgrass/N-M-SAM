# Results and limitations

CURRENT USER OVERRIDE: CODE_COMPLETE / UNIT_TESTED are code statuses only.
DATASET_PENDING and GPU_VALIDATION_PENDING apply to future research validation.
No further real CIFAR reads, FakeData loops, checkpoint sampling or A/B/C research
experiments are authorized. All experiment CLIs require explicit --execute.
Historical short runs in EXPERIMENT_LOG precede the override; they are not paper
evidence and do not authorize additional runs. Dataset replacement found earlier
does not clear the user's current requested DATASET_PENDING deployment status.

Research code availability does not establish improved generalization or novelty.
Only bounded CPU experiments are authorized. Full-epoch/multi-seed/GPU studies
require additional user authorization. Old CIFAR results are excluded.
