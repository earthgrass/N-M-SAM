# 三个独立 Mask Selection 方案的统一比较与研究建议

状态：DESIGN_ONLY。三份文档均未转化为生产选择器，未运行科研实验。
原项目要求的 A/B/C 已作为通用数学诊断工具实现；这里的方案1/2/3不是
给原A/B/C改名。尤其方案3不依赖 Hessian 模型，方案2不依赖两梯度曲率估计。

对应文档：

- [方案1：对称割线鲁棒模型](MASK_SELECTION_PROPOSAL_1.md)
- [方案2：鲁棒上/下界切换](MASK_SELECTION_PROPOSAL_2.md)
- [方案3：鲁棒反馈 Bandit](MASK_SELECTION_PROPOSAL_3.md)

## 1. 共同不可变的目标和工程契约

```text
Fρ(Z,M)=max_{P_Mδ=δ, ||δ||₂≤ρ} L(Z+δ;B,s)，Z=P_M W。
```

所有方案都从此目标推导 Mask 决策；L 默认任务 CE，非 optimizer J。
固定参数化、批次/增强、BN/RNG、ρ、sparse scope 与正则口径。
Dense/bias/BN/排除层仍在扰动域，不能只给每个块独立预算。
每个新Mask本身合法2:4，q为永久中心改变，ε/δ为临时内层扰动。
完整step后、其他mask调度前才允许提交新mask，不能在g1/g2之间变化。

单个批次的条件改善不是全数据风险保证；E_B maxδ L_B与maxδ E_B L_B不同。
条件目标一致性也不等于测试泛化、输入鲁棒性或native sparse速度。
支撑受限F下降不能自动证明全空间F下降，后者需要单独的评价对象。

## 3. 统一计算预算，不隐藏验证成本

标准Sparse-SAM按当前工程计为每步2F/2B。默认候选选择目标采用匹配训练的
train_fixed_batch，且方案1/2的完整端点值识别要求identity STE和正确正则校正。

- 方案1/2：没有新增网络遍历，仍须测O(P)显存带宽与K块处理。建议初始预算
  K≤1024、τ≥20；方案1局部解算最多32批量迭代，超时或证书未收敛就跳过。
- 方案3：τ=50时额外前向次数约1%，无额外反向；实际wall-time尚未测量。
- 若坚持eval状态选择：方案1每帧额外2F/2B；方案2额外1F/1B；方案3额外2F/1B。
  这些是明确的独立版本，不可混报默认成本。
- P≈1100万时一个FP32向量约44MB，两向量约88MB。额外BN/RNG、trace、
  functional复制与无梯度F激活不在“两个向量”数字中，必须报告完整峰值。
- A/B/C通用验证工具的HVP、候选多步inner计算是**单独批准的小样本研究成本**，
  不准偷偷变成训练每步/每块操作。一两个HVP不能证明全网络β或残差谱界。

可行性验收应同时看F/B次数、峰值显存、端到端吞吐、pack开销及接受/探索收益。
摊销额外时间若无法限制在预声明预算（例如≤5%），则该配置不满足此研究的成本要求。
用更大计算量取得更好分数不能算通过。
严格2:4合法性三者均保持；当前dense masked PyTorch不是native稀疏加速实现。

## 4. 怎样真正支持或否定方案

先审阅理论，再单独批准GPU实验；当前不执行下列计划。

### 统一基线与观察对象

保留六组已实现baseline；同model、split、seed、scope、J正则、ρ、scheduler、
数据增强、mask interval及总资源预算。新方案分别运行，先不组合。
只用训练内部校准/独立validation选择策略，不用test挑Mask。
报告ΔL、ΔS_proxy、ΔF_proxy、候选regret/排名、q/ρ、mask翻转、BN状态、额外操作与时间。
网络有限步inner只能标proxy；解析二次参考的精确性不能外推给ResNet。

### 方案1需要的关键证据

低秩Q能在不同层/阶段/位移桶中稳定改善对候选鲁棒目标的排序；
残差/路径误差能解释失败，且三维求解和缓存满足预算。若残差主导、
激活切换频繁导致模型失效，或只能靠大量HVP修补，则不支持作为训练选择器。

### 方案2需要的关键证据

有效/经验β分别记录；展示上界覆盖、界间隙、接受率和错误接受率。
若保守界完全冻结Mask，或经验界不可控地误接受，就不支持主选择用途。
有限样本中“没有错误接受”不是全邻域证明；不得夸大为严格证书。

### 方案3需要的关键证据

先检验proxy/真实可算F的差距与重要性估计方差，再检验动作概率能否识别有用策略。
同时展示no-change/Magnitude概率、探索损伤、候选族遗漏、冻结snapshot与在线轨迹差异。
若仅proxy regret变好、对真实参考F/validation没有相应收益，不能支持目标改进。
缺乏损失界/非预知协议时只算启发式版本，不能使用理论regret作背书。

三者都应包含反例和停止条件，不先假定创新成立，也不以测试精度单种子上涨取代机制证据。

## 5. 推荐：先研究方案1，不立即实现正式选择器

推荐顺序为：**方案1优先；方案2作独立保守对照；方案3作为不依赖局部曲率的备选。**
这不是按既有代码偏好排名，依据是以下可被实验否定的判断：

1. 方案1以零额外训练反向使用已有两梯度，仍明确处理最终F的中心和新扰动域。
   相比单权重Taylor，它给出可计算的全网络鲁棒内层，且没有消去非零梯度项。
2. ≤3维降维是对明确模型的严格结论，生产成本可以设硬预算，不需百万块HVP。
   这给了“足够表达力与足够低成本之间是否存在有用折中”的清晰研究问题。
3. 它最脆弱的条件是残差曲率与局部性，而已完成的通用A/B诊断可直接揭示这些失败。
   因此能够较快决定继续或放弃，不必先扩展成复杂完整算法。
4. 方案2的条件改善保证更清晰、实现更简单，但其β可能非常保守，导致几乎无选择。
   不能只因为保证形式漂亮就假定它最有效。
5. 方案3避开大q的旧中心Taylor误差，可能有独特价值，但动作族、反馈噪声及训练
   轨迹耦合让解释更复杂，bounded-loss理论在当前无约束网络中也未自动成立。

**推荐不代表认可残差小、界可用、性能会提升或它具有新颖性。**
如果首轮批准的机制验证显示方案1的残差/时点/激活误差盖过候选差异，应明确停止，
而不是无限增加HVP。届时根据方案2接受率和方案3反馈可辨识性重新选择路线。
正式新Mask Selection代码、训练配置和任何方法实验均须等用户审阅批准。

## 6. 文献位置及未完成的新颖性审计

已核对的主要来源（用于定位已有理论，非效果背书）：

- [SAM 原论文](https://arxiv.org/abs/2010.01412)：最终目标的原始背景。
- [Google 固定实现](https://github.com/google-research/sam/blob/dae9904c4cf3a57a304f7b04cecffe371679c702/sam_jax/training_utils/flax_training.py)：JAX/Flax训练语义。
- [Powell symmetric Broyden discussion](https://optimization-online.org/2010/06/2653/)：对称模型最小Frobenius改变量思想已有基础。
- [SSAM](https://arxiv.org/abs/2210.05177)：已有稀疏扰动SAM方向；扰动稀疏与严格权重N:M不能自动等同。
- [AdaSAP](https://arxiv.org/abs/2306.14306)：已有sharpness-aware pruning；必须比对目标/约束/评分与预算。
- [RigL](https://proceedings.mlr.press/v119/evci20a.html)：已有动态稀疏拓扑训练背景。
- [Auer等bandit论文](https://epubs.siam.org/doi/10.1137/S0097539701398375)：重要性估计与在线regret的既有基础。
- [SA-SAM 2026预印本](https://arxiv.org/abs/2609.14274)：检索发现的近期相关方向，仍需全文逐项新颖性比对。

这是有限范围检索，不是“没有先行工作”的证明。特别是拟牛顿、bandit、
smoothness-bound pruning、鲁棒剪枝等可能存在更直接重叠，正式贡献声明前需完整审计。
研究讨论稿的历史六组成绩不参与这些方案的支持证据。
