# Figures intentionally not generated

The requested APBR-GPT accuracy, 2x2 full-network ablation, and layer-distribution figures require full-network QQ/HQ/QH results. The preregistered single-layer stop rule fired before those experiments, so generating such figures would imply nonexistent results.

The real pilot data are preserved in `lambda_sensitivity.csv`, `layer_diagnostics.csv`, and `runtime_memory.csv`. No illustrative or synthetic values were substituted.
