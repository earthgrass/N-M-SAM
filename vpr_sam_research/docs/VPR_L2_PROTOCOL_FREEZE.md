# Full VPR-L2 seed 0: frozen exploratory protocol

Only one new 200-epoch dense trajectory is authorized. The sole research
configuration difference from V1 `d4c58d66b248b620e0e058b92e79100f173970a6`
`vpr_seed0.json` is `optimizer.method: vpr -> fixed_l2`. The only other
configuration difference is the isolated output path. The exact V1 JSON and
historical audit evidence are copied under `docs/vpr_l2_reference/`, with SHA256
receipts. The machine-readable diff is generated by precheck.

The existing frozen implementation first calculates epsilon_D using its stable
log-domain path, casts to FP32 and rescales the result to L2 radius rho. It is
the approved implementation of rho*A^2*g1/||A^2*g1||, allowing FP32 rounding.
Global p_i and log-radius feedback are unchanged; FP64 states, zero initial
log-radii, fixed gamma, unchanged full trainable parameter set and fixed d.
No EMA, clipping, volume recentering, new loss or blockwise geometry is used.
The existing geometry.py, step.py and training engine are unchanged.

The passive observer measures actual FP32 parameter additions before the second
forward. It checks the existing approved radius tolerance (relative 2e-5,
absolute 1e-12), finite diagnostics and a conservative IEEE FP32 addition error
bound. Ellipsoid boundary norm is recorded but is deliberately not gated to rho
for fixed_l2. Gradients and geometry use the computed epsilon, as in V1.
Linear strength and direction cosine use the already computed g1 on steps
1+352*k, one predetermined batch per epoch; no extra training forward/backward,
RNG draw or state mutation. Center and adversarial losses and g1/g2 are the
unchanged Stepper values. The first BN forward updates running buffers; the
second uses batch statistics with track_running_stats=False. No AMP, TF32 or
compile is introduced.

All other hyperparameters are copied, not reconstructed: CIFAR-ResNet18,
CIFAR10 45000/5000, 200 epochs, 128 batch, SGD .1/.9/.0005, cosine eta_min=0,
rho=.05, gamma=5.482145661475941e-8, warmup=0, FP64 geometry, deterministic,
crop4/flip/normalize and Cutout0. cuda:0 must be the approved RTX5090 UUID
fc8784a7-85a2-2bcd-d2e2-f36ef021616c. Threads and complete environment must
match V1. The inherited recovery configuration is schema-required reference
data only; no V2 code path calls recovery. Legacy configs remain historical
repository references; this launcher's sole whitelist is approved_vpr_l2/seed0.json.

Initialization, split, augmentation streams and all 70400 batches' ID order
must match V1 seed0. Augmentation code and RNG modules must have identical
V1 hashes. Precheck records first augmented batch SHA256 for each of 200
epochs and recomputes the full order hash. No V1 checkpoint is loaded in V2.

After exactly 200 epochs/70400 steps, final-only Magnitude 2:4 pruning uses
exclude_first_last and dense tail. Raw Hard keeps BN buffers unchanged. A
separate model copy recalibrates BN using the previously frozen 4096 train IDs,
unaugmented batches128, reset running stats, momentum=None, BN-only train mode,
32 batches, no gradients or parameter updates. Evaluate full5000 validation
at batch256. This does not replace Raw Hard. Public sphere probes use rho=.02,
the fixed first ten validation batches256 and the masked subspace for Hard.
Endpoint diagnostics use the same frozen1024 validation IDs/batch128 as V1,
eval-mode BN and rho=.05, and separately measure finite loss increase and the
same-point spherical counterfactual. All historical comparisons use audited
V1 seed0 JSON/CSV; code snapshots and checkpoint hashes remain explicit.

Fail closed on NaN/Inf, radius/rounding/volume gates, provenance mismatch, OOM,
hardware failure or disk reserve under4GiB. Do not retry, resume automatically,
adjust gamma, lower gates, change device, or stop for early accuracy. Independent
controller and subprocess process groups survive SSH disconnection; one run
only, followed by approved evaluation, report generation and termination.
Reserve at least8GiB before launch; existing V1 results and runtime remain intact.

Run from an isolated, clean Git worktree with a physically copied independent
venv and dataset, reinstalling the editable package to the new src path:

```
.venv/bin/python -m pytest -q --basetemp=artifacts/pytest-vpr-l2
.venv/bin/python scripts/vpr_l2_precheck.py
nohup .venv/bin/python -u scripts/vpr_l2_controller.py >artifacts/vpr_l2/controller.log 2>&1 </dev/null &
```

The controller writes silent local telemetry and durable failure evidence. No
routine user notifications. No test-set metrics, seed1/2, recovery, Gamma
search, Conv-only/BN-excluded variants or further GPU jobs are authorized.
"2:4 blockwise geometry redistribution" is recorded only as a future idea;
it is not implemented in this experiment. Single-seed outcomes are exploratory;
epsilon L2/rho=1 alone cannot establish a research performance advantage.

Root-level VPR_L2_*.md are generated delivery reports (ignored by Git); the
protocol source is this tracked document. Complete result reports are produced
only after successful training and evaluation. Original failures remain retained.
