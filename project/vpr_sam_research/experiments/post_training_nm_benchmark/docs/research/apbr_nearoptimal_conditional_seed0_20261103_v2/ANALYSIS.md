# APBR × 条件贪心 OBS：Seed 0 单层 Pilot 分析

## 研究问题与对照

本 Pilot 检验 APBR 训练期几何状态能否在物理 OBS 代价相近时提供独立的 Mask 选择信息。选择规则先把每步物理条件 OBS 单坐标代价限制在最小值的 1.01 倍内，再用 `|w exp(-s)|²` 裁决；第二步使用虚拟删除后的权重 `w'` 和条件逆曲率。选出的两个坐标仍接受**相同的物理联合 OBS 补偿**。这是组内条件贪心的几何裁决，不是官方 ExactOBS，也不是原生 SparseGPT。

四臂在同一个原版 APBR-VPR Seed 0 Epoch-200 Dense checkpoint 上运行：最低物理分数、单位几何、真实几何、组内固定打乱几何。1024 张官方 CIFAR-100 Train 图片用于构建 `layer1.0.conv1` 的 Hessian；另 1024 张 Train 图片仅用于训练侧诊断，两组不重合。后者参与过原始 Dense 训练，因此不是独立验证集。没有读取 Test。

父 checkpoint SHA256：`4332079becdb58fb50f0e68b8bd0dcc251db0184a6050facb524817520a51d82`。官方 archive SHA256：`85cd44d02ba6437773c5bbd22e183051d648de2e7d6b014e1ef29b855ba677a7`。校准 ID SHA256：`3b7da27d79762235c87f18571bc73224d6e6f2b3ba663b7d9a4a3de312f23157`。其余源码与数据哈希见 `preflight.json`。

## 结果

| 选择规则 | 训练侧准确率 | 训练侧 CE | 物理层重建二次误差 | 相比物理基线翻转的位置 |
|---|---:|---:|---:|---:|
| 物理条件贪心 | 100.00% | 0.00242304 | 0.00200778 | 0 |
| 单位几何裁决 | 100.00% | 0.00242261 | 0.00200091 | 132 |
| **真实 APBR 几何** | **100.00%** | **0.00242261** | **0.00200091** | **132** |
| 打乱 APBR 几何 | 100.00% | 0.00242240 | 0.00200248 | 144 |

该层共有 9,216 个四元组；真实几何路径中第一次选择有 4,317 组、第二次有 3,703 组出现至少两个 1% 近优候选。虽然近优候选常见，**真实 APBR 与单位几何的第一次、第二次选择、最终 Mask 和补偿权重都逐项完全相同**。打乱几何相对单位几何改变了 12 个位置。真实几何的物理误差比纯物理基线低约 0.34%，但这个变化完全由近优窗口的单位权重裁决带来；当前层没有可归因于学得 APBR 几何的增益。训练侧准确率已饱和，CE 差异小于百万分之一，不支持任务级收益结论。

一条真实输出行另用锁定的官方 TrueOBS 做有界参照：Cholesky info=0，无回退，物理二次误差为 `1.78788e-5`；四个 Pilot 变体在该行均为 `7.70675e-5`。官方 TrueOBS 跨四元组按全行分数排序，本 Pilot 按固定四元组顺序，因此该差距包含处理顺序和数值实现差异，不能归因于几何裁决。该参照只运行一行，未运行整层或全模型 ExactOBS。

## 数值与身份门禁

- 新适配器在 τ=0 时对历史条件贪心适配器的 Mask、选择顺序和补偿权重实现 bitwise replay；合成 SPD 的独立约束求解、窗口边界、虚拟第二步、严格 2:4、零值及 finite 均通过。目标测试合计 **35 passed**。
- 四个真实层输出都是 bool keep-mask；每个完整四元组恰好保留 2 个，均删除 18,432/36,864 个位置；删除权重严格为零，全部有限。
- 四臂 checkpoint 均指向同一父 checkpoint，权重、Mask、源代码和结果文件的 SHA256 见 `SHA256SUMS.txt`；清单复核 8/8 项一致。
- 本机 PyTorch `2.13.0+cpu`，无 CUDA；这些不是 GPU 门禁或正式全模型准确率。
- v1 因稠密权重视图别名被作废并保留。v2 使用独立 `clone()`，且运行结束核验 Dense 权重已恢复；不要使用 v1 的四臂汇总。
