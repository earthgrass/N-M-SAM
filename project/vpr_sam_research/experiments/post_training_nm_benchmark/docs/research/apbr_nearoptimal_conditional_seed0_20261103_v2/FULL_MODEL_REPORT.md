# APBR 几何近优条件贪心 OBS：CIFAR-100 Seed 0 全模型探索

## 固定流程

在原版 APBR-VPR Seed 0 Epoch-200 Dense 父模型上，使用官方 CIFAR-100 Train 的历史固定 1,024 张图片构建 19 层卷积 Hessian。每个 2:4 组的第一次选择先按物理条件 OBS 单坐标代价形成固定 1% 近优集合，再以 `|w exp(-s)|²` 裁决；虚拟删除后更新剩余权重与条件曲率，第二次选择也用同样的近优规则，但几何分数基于虚拟权重 `w'`。确定删除对后，从原始当前组权重出发做**同一个物理联合 OBS 补偿**。无恢复训练、BN-only 或其他梯度更新。全部 checkpoint 和 Mask 先冻结并计算 SHA256，再各做一次 10,000 张 Test。

四个 APBR 同父消融同时完成：纯物理条件贪心、单位几何、真实 APBR 几何、组内固定打乱几何。主跨父对照复用此前完成且身份核验通过的 **SAM Dense Seed 0 + 同一纯物理条件贪心 OBS**，没有重复剪枝或 Test。

## 主比较

| 完整路径 | Dense Final | 剪枝及补偿后 Test | 相对本身 Dense | Test CE |
|---|---:|---:|---:|---:|
| SAM + 条件贪心 OBS | 78.84% | **77.84%** | −1.00 pp | 0.828370 |
| APBR-VPR + 同一条件贪心 OBS | 78.68% | 77.72% | −0.96 pp | 0.829459 |
| APBR-VPR + 几何近优条件贪心 OBS | 78.68% | 77.83% | −0.85 pp | 0.829065 |

两条最终结果相差 **0.01 pp，即 10,000 张 Test 中 1 张**。APBR 的剪枝前 Dense 较低 0.16 pp，剪枝后差距缩小到 0.01 pp；这只能说明此 Seed 的完整路径表现接近，不能单独归因 APBR 几何。

| APBR 同父选择消融 | Test Accuracy | CE | 相对纯物理的 Mask 翻转位置 |
|---|---:|---:|---:|
| 纯物理条件贪心 | 77.72% | 0.829459 | 0 |
| 单位几何近优裁决 | 77.76% | 0.829073 | 856,104 |
| **真实 APBR 几何近优裁决** | **77.83%** | **0.829065** | 854,824 |
| 打乱 APBR 几何近优裁决 | 77.82% | 0.829238 | 855,308 |

真实几何相对单位几何改变 13,062 / 11,157,504 个位置（0.117%），涉及 6,225 个四元组；相对打乱几何改变 15,870 个位置。真实几何比单位几何高 0.07 pp、比打乱几何高 **0.01 pp**。这只有一个 Seed，且打乱对照几乎相同，**尚无稳健证据证明学习到的 APBR 坐标对应关系带来独立收益**。单层 `layer1.0.conv1` 上真实与单位几何完全相同；全模型的微小差异主要来自更深层。

## 审计与限制

- 两个 Dense 父模型使用同一初始权重、正式配置、模型结构、官方数据和校准 ID；均为 Epoch 200 / 78,200 steps。主表的 Dense 训练路径不同，APBR 分支还使用几何裁决，因此不是仅改变几何状态的因果消融。同父四臂才是几何机制对照。
- 新适配器 τ=0 对历史条件贪心的合成数值门禁实现 bitwise replay；全模型纯物理臂与历史 APBR 条件贪心 checkpoint 在 19 层的 Mask、所有模型权重逐项 Bitwise Equal。目标回归 **35 passed**。
- 独立产物审计：四组均为 19 层 bool keep-mask、严格 2:4、各删除 5,578,752 / 11,157,504 个位置；删除位严格为零、数值有限，BN 和排除层与父模型 bitwise 相同。四份 checkpoint 的哈希均与 Test 前冻结清单一致；训练/校准/剪枝期间 `test_accessed=false`。
- 本机运行环境为 PyTorch `2.13.0+cpu`，无 CUDA；时间与显存不能当作 GPU 成本。完整模型虽已固定 Test，但仍是 Seed 0 探索结果，不进入既有三 Seed 正式主表。
- v1 单层产物因权重视图别名作废并保留；正确的单层 v2、此次全模型结果与历史正式文件相互隔离。没有改动正式训练、原生 SparseGPT 或 APBR 源码。

机器可读证据：`artifacts/apbr_nearoptimal_conditional_seed0_full_cpu_20261103_v1/results.json`、`pre_test_freeze.json`、`independent_audit.json`；SAM 历史对照：`artifacts/sam_singleton_conditional_seed0_cpu_20261103/results.json`；逐源哈希见两套结果中的 `source_sha256` 和本目录 `SHA256SUMS_FULL.txt`。

**判断：**该组实验没有显示 APBR 几何近优条件贪心稳定超过 SAM 条件贪心；本 Seed 仅差 1 张 Test 图片。若要把 APBR 作为论文核心，需要预先冻结多 Seed、同父几何/打乱对照并复现可观测增益；不能把这 0.01 pp 写作方法优势。
