## Minimal counterexample and feasible sets

For W shape[1,4,3,3], canonical group0=[0,1,2,3], native Conv
group0=[0,9,18,27]. A Mask keeping positions0,1 in every canonical block,
except block[8,9,10,11] retaining10,11, is legal canonical2:4 but retains
only one coordinate of native group0. Thus the legal sets differ, not merely
the printed tensor layout. Actual current eligible kernels include3x3, so
this is relevant;1x1 agreement does not resolve it.

## OBC algorithm-preservation proof and tests

Let canonical Conv patch matrix X be generated by the **original** nn.Unfold
path. The native code accumulates H=2/n XX^T, retaining its matmul/cast order.
The local reconstruction quadratic is0.5 δw^T H δw. Under any permutation P,
δw'=Pδw and H'=PHP^T give the same quadratic. Native Conv uses its channel-last
P and transforms output back; the adapter uses P=I through the already
supported official Linear API. W and H are in the same canonical coordinates,
and the stored Boolean selection uses those same coordinates. No Hessian is
reordered independently of weights; no post-hoc Mask relabelling occurs.

The desired legal-set change is explicit: canonical row groups replace native
channel-strided groups. Within that declared constraint, all original greedy
scores, inverse updates and surviving-weight compensation execute unchanged.
For fixed surviving set K and dropped set D, the test checks
w'_K = w_K + H_KK^(-1)H_KD w_D and lower reconstruction error than plain
zeroing. This proves compensation consistency, not global combinatorial
optimality or equivalence of different grouping constraints.

Earlier tests cover Linear,3x3 Unfold-H and compensation. Added tests verify
native W/H/Hinv permutation and inverse, objective invariance, a genuinely
different feasible Mask, and noncontiguous3x3 Parameter equivalence. Tied
identity-H weights explicitly prove native removes0,1/keeps2,3. It does not
silently adopt Magnitude's keep0,1 convention. All-zero kept coordinates retain
an explicit legal selection Mask in the existing test.
