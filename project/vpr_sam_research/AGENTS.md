# VPR-SAM 项目约束

- 本目录是独立工程。不得在运行时导入父目录历史工程，或默认读取其数据、配置、checkpoint。
- 历史代码、数据、实验结果与 checkpoint 不得修改、覆盖或删除。
- 所有新数据及实验产物保存到本目录内；不把运行产物或虚拟环境提交 Git。
- 正式实验必须随机初始化。resume 仅恢复本工程同一 run 的健康 checkpoint，不是历史权重初始化。
- 主方法固定全参数空间全局反馈/全局等体积；d 初始化后固定。
- epsilon=rho*A^2*g1/||A*g1||；p_i=epsilon_i^2/sum(epsilon^2)；s_next=s+gamma*(1-d*p)。
- 保留两次梯度、参数恢复及基础优化器结构。不得静默改成逐层/逐块反馈。
- 第一版不添加 EMA、半径裁剪、体积回正、新损失、Predictor 或 Compensation。
- 全零扰动跳过几何更新；非有限数值显式失败。失败对象不得继续或保存为有效 checkpoint。
- N:M、正式超参数、种子预算、恢复和模型选择协议仍待用户确认，不得默认采用2:4。
- smoke 使用显式标记的合成数据。正式数据失败必须报错，不得 fallback 成合成数据。
- 准确区分 CPU 测试通过、CUDA smoke 通过和正式实验结果；不得相互替代。
- 影响数学定义、公平性或复现性的改动先与用户讨论。
- 未获用户明确批准，不连接服务器、启动正式长程训练或批量提交任务。
- 验证命令：`python -m pytest -q --basetemp=artifacts/pytest-temp`。
